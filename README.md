# 本机续火助手（方案 A）

这是一个只在 Windows 本机运行的抖音聊天辅助工具。它用你电脑上的 Edge 或 Chrome 打开抖音聊天页，让你扫描会话、选择好友、预览每日消息，并在你明确授权后执行发送。

> 重要：抖音用户协议限制自动化程序。此工具不绕过验证码、不隐藏自动化特征、不调用非公开签名接口，也不能保证火花一定续上。请使用不重要的账号、小范围测试，并自行承担账号风险。

## 当前能力

- 只读扫描最近会话，并在本机保存好友列表。
- 搜索、勾选并保存目标好友；同名好友会被安全跳过。
- 支持 `{{friend}}`、`{{date}}`、`{{time}}`、`{{weekday}}` 消息变量。
- 预览模式绝不调用发送流程。
- 实际发送默认关闭，首次开启必须输入风险确认短语。
- 发送前后二次核对聊天标题，并等待消息气泡出现。
- “消息已确认”和“火花显示变化”分开记录。
- 同一好友当天已确认或结果不确定时，不再自动重试。
- 可选每日定时；控制程序关闭后，定时不会运行。
- 数据和浏览器登录资料只保存在本机。

## 第一次使用

1. 安装 [Node.js 22 或更新版本](https://nodejs.org/zh-cn/download)。
2. 双击 `首次安装.cmd`。
3. 安装完成后，浏览器会打开 `http://127.0.0.1:4317`。
4. 点击“打开登录页”，在单独打开的浏览器里手动完成登录。
5. 回到控制面板，点击“只读扫描”，选择好友并保存。
6. 先生成预览，确认消息和好友都正确。
7. 如果决定承担风险，再开启“允许实际发送”。

以后双击 `启动控制面板.cmd` 即可。用完可双击 `停止控制面板.cmd`。

## 推荐试运行顺序

1. 保持“允许实际发送”关闭，只扫描和预览。
2. 只选 1 个可以配合测试的账号。
3. 手动运行一次，核对聊天气泡与火花状态。
4. 连续观察数天，确认页面结构稳定后再考虑每日定时。
5. 页面改版、出现验证码、登录异常或结果不确定时，立即停用实际发送。

## 开机启动（可选）

右键 `scripts/安装开机启动.ps1`，选择“使用 PowerShell 运行”。卸载时运行 `scripts/移除开机启动.ps1`。开机启动只负责启动本机控制程序，不会自动开启“允许实际发送”。

## 数据位置

默认数据保存在：

`%LOCALAPPDATA%\DouyinSparkLocal`

其中包含设置、运行记录和一个独立浏览器登录目录。不要把该目录上传或发给他人。删除前请先停止控制面板。

## 开发与检查

```powershell
npm install
npm run check
npm start
```

服务仅监听 `127.0.0.1:4317`，不会向局域网开放控制面板。

## 已知限制

- 抖音网页结构会变化，扫描或发送定位可能随时失效。
- 好友身份主要由显示名称和头像路径核对；同名会话必须先在抖音里设置唯一备注。
- 网页端是否展示全部好友取决于抖音当前聊天页；扫描结果不等于完整通讯录。
- 消息气泡出现不等于火花已经续上，部分规则可能要求对方互动。
- 没有使用官方的个人私信自动发送接口，因为公开能力不覆盖这个场景。

## 常见问题

### 出现 `ERR_NETWORK_ACCESS_DENIED`

这通常表示控制面板是从受限的开发预览环境启动的，并不是抖音账号或网络本身出错。先运行 `停止控制面板.cmd`，再直接从 Windows 文件夹双击 `启动控制面板.cmd`。新版会识别这种情况并显示中文处理提示，不再展示原始浏览器错误。
